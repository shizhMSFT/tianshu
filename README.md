# Tianshu

In this fast-changing world, there are too many things for a curious person to learn, internalize, and then externalize in limited time.

Tianshu is a set of skills plus a user-friendly interface built with the Copilot SDK, helping you:

- Research and learn domain knowledge with notes written down in a GitHub repository.
  - Capture more than text, including tables and diagrams.
  - Generate quizzes to ensure understanding.
  - Keep theory grounded in practice by automatically designing and running labs with written reports.
- Build an external cognitive system by transforming methodologies into mental models.
  - Brainstorm with domain knowledge.
  - Judge whether an idea is worth expanding.
- Establish an idea bank through memorizing and dreaming.
- Share knowledge and ideas with animated slides.

Learning is hard. Tianshu makes it delightful.
