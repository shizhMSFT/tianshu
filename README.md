In this fast-changing world, there are too many stuffs for a person full of curiosity to learn, internalize, and then externalize, given limited time.

Tianshu is a set of skills running in GitHub Copilot app, helping you to

- Research and learn domain knowledge with notes written down in a GitHub repository
    - Not just text but tables and diagrams
    - Quiz is generated to ensure your understanding
    - Theory shouldn't drift from practice -- auto design and do labs with written reports
- Build an external cognitive system by transforming methodologies into mental models
    - Brainstorm with domain knowledge
    - Judge an idea if it worths expanding
- Establish an idea bank through memorizing and dreaming
- Share knowledge / ideas with animated slides

## Skills

| Skill | What it does |
| --- | --- |
| [`learn`](.github/skills/learn/SKILL.md) | Research a topic and create prerequisite-aware, source-backed learning materials. |
| [`quiz`](.github/skills/quiz/SKILL.md) | Create an interactive, source-grounded study experience from learning materials. |
| [`practice`](.github/skills/practice/SKILL.md) | Design, run, and report a reproducible hands-on lab. |
| [`build-mental-model`](.github/skills/build-mental-model/SKILL.md) | Build or refine a system of testable, connected mental models. |
| [`idea`](.github/skills/idea/SKILL.md) | Capture a raw idea as a concise, durable repository record. |
| [`dream`](.github/skills/dream/SKILL.md) | Synthesize related ideas, archive duplicates, and produce an auditable report. |
| [`judge`](.github/skills/judge/SKILL.md) | Evaluate whether an idea is worth expanding using relevant mental models. |
| [`brainstorm`](.github/skills/brainstorm/SKILL.md) | Generate domain-grounded ideas and judge them against durable mental models. |
| [`knowledge-to-pptx`](.github/skills/knowledge-to-pptx/SKILL.md) | Turn knowledge into a designed, validated PowerPoint with a consistent visual and motion system. |

Learning is hard. Tianshu makes it delightful.
