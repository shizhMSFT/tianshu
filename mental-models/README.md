# Mental models

This directory is Tianshu's durable cognitive system. Each artifact states its intended use, mechanism, evidence, boundaries, dependencies, and next test so later reasoning can reuse it without relying on the conversation that created it.

## Core models

| Model | Status | Purpose |
| --- | --- | --- |
| [Outcome-Guided Exploration](outcome-guided-exploration.md) | `exploring` | Choose a bounded next action that advances an incomplete outcome while reducing decision-relevant uncertainty. |
