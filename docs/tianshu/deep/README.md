# Deep track

The deep track builds a durable operating model of all nine Tianshu skills. It begins with the shared Copilot foundation, then traces artifact authority, every skill-family mechanism, supported handoffs, recovery rules, and an end-to-end capstone. Confirmed Git/GitHub and Markdown knowledge is assumed; Copilot skill-session behavior is taught by the shared prerequisite.
